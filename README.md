## ⚡ ALGORITHM COMPLEXITY

| Complexity | Notation | Performance |
|---|---|---|
| Constant | `O(1)` | 🟢 Excellent |
| Logarithmic | `O(log n)` | 🟢 Very Good |
| Linear | `O(n)` | 🟡 Good |
| Linearithmic | `O(n log n)` | 🟡 Efficient |
| Quadratic | `O(n²)` | 🟠 Slower |
| Exponential | `O(2ⁿ)` | 🔴 Expensive |
