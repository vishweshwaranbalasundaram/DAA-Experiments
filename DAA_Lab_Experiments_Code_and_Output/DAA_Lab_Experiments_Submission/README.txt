DAA LAB EXPERIMENTS

This folder contains the C source code and corresponding text output for each experiment.

Folder structure:
  Each topic has its own folder.
  Each experiment folder contains:
    code.c       - C source code
    OUTPUT.txt   - Sample program output

To compile and run using GCC:
  gcc code.c -o program
  ./program

On Windows (MinGW):
  gcc code.c -o program.exe
  program.exe

Note: OUTPUT.txt contains sample text output for reference. Run the source code
with the required input to verify the result in your environment.
